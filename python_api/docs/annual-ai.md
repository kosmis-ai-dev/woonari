# 사주 기반 연간 AI un

`POST /v1/fortunes/yearly` 또는 `POST /v1/un/2014yearluck`으로 실행합니다. 두 번째 경로 이름은 서비스 식별자이며 2014년으로 제한되지 않습니다. 1900~2050년의 양력 연도를 지원하고 조회일은 출생일 이후여야 합니다.

```json
{
  "birth": {
    "year": 1974, "month": 3, "day": 2,
    "hour": 8, "minute": 30,
    "calendar": "solar", "gender": "male"
  },
  "target_date": "2027-01-01",
  "include_ai": true
}
```

성별은 테스트 예시 값이므로 실제 입력에 맞게 수정합니다. 별칭 경로에서는 `parameters: {}`를 추가할 수 있습니다. Swagger 첫 예시는 AI 본문 생성이며 두 번째 예시는 계산 전용입니다.

## 해석 범위와 응답

개인 사주팔자·오행·일간과 대상 연도의 간지·십성·십이운성 관계를 바탕으로 본문을 작성합니다. 안내 기간은 양력 1월 1일~12월 31일입니다. 대상 연도의 대표 간지는 입춘 이후인 7월 1일 12시(KST)를 기준으로 하며, 1월의 실제 절기 연도와 같다는 뜻은 아닙니다.

AI 본문은 다음 7개 항목을 포함합니다: 총운, 직장/사업/학업, 재물/생활 관리, 관계, 건강/생활 습관, 변화, 준비/실천. 전통적 상징에 따른 해석이며 미래 사건이나 월별 길흉을 확정하지 않습니다.

| 응답 필드 | 내용 |
|---|---|
| `content` | 요약·7개 항목 해석·조언을 연결한 본문 |
| `interpretation.summary` | 연간 해석 요약 |
| `interpretation.sections` | `topic`, `text`로 나눈 7개 항목 |
| `interpretation.practical_advice` | 실천 조언 |
| `result` | 운세 종류·조회 기간·개인 사주·연도 관계 계산 결과 |

**별점·점수·확률·부적은 제공하지 않습니다.** 내부 계산 방식·자료 출처·모델 검증 계약은 응답에 포함하지 않습니다.

`include_ai=false`는 본문 없이 `result`만 반환하며 모델 호출·일일 차감이 없습니다. `true`는 AI를 호출하고 실패를 포함해 한국시간 일일 최대100회 한도를 사용합니다. 자동 재시도는 하지 않습니다. AI 연결·모델 응답·본문 검증 오류는 정상 본문으로 대체하지 않습니다.

## 개발용 자료 기록

연간 본문은 별도의 운세 문구·점수 DB를 읽지 않지만 사주·만세력 계산 자료는 필요합니다. 복원된 과거 연간 표와 빈 2027년 초기 행은 현재 본문 생성의 차단 조건으로 사용하지 않습니다.

복원 자료의 빈 행·키 매핑 상태는 개발 환경의 `app.restored_fortune.restored_data_status(2027)`로 확인합니다. 해당 진단은 공개 API에서 제공하지 않습니다. 내부 계산·출처 이력은 [복원 조사 기록](../../docs/mssql-restore.md)에 보존합니다.
