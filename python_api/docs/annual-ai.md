# 사주 기반 연간 AI un · CR-018

`POST /v1/fortunes/yearly` 또는 `POST /v1/un/2014yearluck`으로 실행합니다. 두 번째 경로 이름은 기존 서비스 식별자이며 2014년으로 제한되지 않습니다. 1900~2050년의 양력 연도를 지원하고 조회일은 출생일 이후여야 합니다.

```json
{
  "birth": {
    "year": 1974, "month": 3, "day": 2,
    "hour": 8, "minute": 30,
    "calendar": "solar", "gender": "male"
  },
  "target_date": "2027-01-01",
  "include_ai": true
}
```

성별은 테스트 예시 값이므로 실제 입력에 맞게 수정합니다. 별칭 경로에서는 `parameters: {}`를 추가할 수 있습니다. Swagger 첫 예시는 AI 본문 생성이며 두 번째 예시는 계산 전용입니다.

기존 만세력과 ASP dotong 프로필의 사주팔자·오행·일간을 유지합니다. 대상 연도의 대표 간지는 해당 연도 7월 1일 12시(KST)를 기존 만세력의 절입 계산에 넣어 확정합니다. 이는 입춘 이전인 1월 조회일 때문에 전년도 간지가 선택되는 것을 피하는 명시적 연간 안내 규칙이며, 기존 ASP 연간 DB 조회 규칙의 재현은 아닙니다. 안내 기간은 양력 1월 1일~12월 31일이고 1월에도 실제 절기 연도가 대표 간지와 같다는 주장을 하지 않습니다.

AI에는 사주팔자·오행·대상 연도 간지·일간 기준 십성/십이운성·각 원국 천간과 연간 천간의 십성 관계를 전달합니다. 본문은 이 사실에 따른 전통적 상징 해석으로 작성하며 7개 고정 항목(총운, 직장/사업/학업, 재물/생활 관리, 관계, 건강/생활 습관, 변화, 준비/실천)을 모두 반환합니다. 원본 연간 문구 DB나 복원 자료를 읽지 않습니다. 만세력 DB 자체는 여전히 필요합니다.

`analysis.method=asp-saju-ai-yearly-v1`, `analysis.scores=[]`이며 `annual-context` 근거의 `ratings.stars`와 `ratings.scores`는 null입니다. 별점·점수·확률·부적은 생성하지 않고 모델이 수치 평점을 쓰면 502 `ai_unrequested_rating`으로 거부합니다. 기존 상용 연간 DB 판정·검증된 미래 사건·월별 확정 길흉으로 표시하지 않습니다. 용신·대운·신살을 새로 계산하도록 맡기지 않습니다.

`include_ai=false`는 content/interpretation이 null인 계산 결과를 반환하며 모델 호출·일일 차감이 없습니다. true는 실제 Claude를 호출하고 실패를 포함해 기존 영속 일일100회 상한을 공유합니다. 자동 재시도는 하지 않습니다. AI 미설정·제공자 오류·근거/항목 계약 위반을 정상 본문으로 대체하지 않습니다.

과거 DB 복원 자료·빈 2027년 판정 행과 키 매핑 미확보는 `/v1/restored-data?year=2027`에 계속 진단으로 남습니다. 현재 AI 본문 서비스에 필요한 의존성은 아닙니다.
